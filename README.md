# 抖音 Web 沉浸式短视频应用 (Douyin Web Pro)

这是一个采用现代化前端工程与黑曜石深色质感打造的抖音高保真 Web 应用原型，集成了沉浸式视频消费、双击点赞动效、旋转黑胶唱片、评论抽屉、视频发布、作者主页及全套系统规划架构。

## 🌟 核心特性
- **沉浸式视频流**：全屏自适应展示，支持鼠标滚轮、键盘上下键/W/S按键、手势滑动无缝切换。
- **经典动效**：
  - 双击视频屏幕触发心形粒子飞舞迸发动画。
  - 右侧黑胶唱片持续旋转，支持静音/原声切换。
  - 创作者关注按钮微动画与头像状态联动。
- **互动体验**：
  - 侧边滑出式评论抽屉，支持即时发表评论与点赞互动。
  - 一键收藏、分享弹窗（微信/朋友圈/QQ/复制链接）。
- **创作与搜索**：
  - 视频发布模态框，支持挑选预置高清素材或输入自定义 MP4 链接，发表后即时插入信息流顶部！
  - 关键词实时搜索与热门榜单热词联想。
- **系统架构全景**：点击左下角「抖音系统全景架构规划」卡片，可直接在应用内阅读从0到1的商业规划与技术落地蓝图。

## 🚀 启动与体验指南
```bash
# 启动本地开发服务器
npm run dev
```
打开浏览器访问：`http://localhost:5173` 即可立即体验！
